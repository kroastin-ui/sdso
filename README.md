# SDSO V13 — GitHub Pages

## Kurulum
1. Bu klasörü GitHub reposuna yükle.
2. `Settings → Pages` bölümünden `Deploy from a branch` seç.
3. Branch olarak `main`, klasör olarak `/root` seç.
4. Kaydet. GitHub Pages birkaç dakika içinde siteyi yayınlar.

## Fotoğraf ekleme
`images/` klasöründeki SVG placeholder dosyalarını gerçek fotoğraflarla değiştirebilirsin.
Dosya adlarını koru:
- gallery-01.svg ... gallery-11.svg
- unit-ia.svg
- unit-fto.svg
- unit-cid.svg
- unit-seb.svg
- unit-air.svg
- unit-hsu.svg
- unit-hsou.svg
- unit-motorcycle.svg

Gerçek JPG/PNG kullanacaksan `index.html` içindeki aynı dosya yollarını `.jpg` veya `.png` olarak değiştir.

## Google Form
`index.html` içinde `GOOGLE_FORM_IA`, `GOOGLE_FORM_FTO`, `GOOGLE_FORM_CID`, `GOOGLE_FORM_SEB`, `GOOGLE_FORM_AIR`, `GOOGLE_FORM_HSU`, `GOOGLE_FORM_HSOU`, `GOOGLE_FORM_MOTORCYCLE` alanlarını gerçek Google Form bağlantılarıyla değiştir.
